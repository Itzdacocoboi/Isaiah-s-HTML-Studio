1. HTML5 Document Skeleton

Every modern web page starts with a proper HTML5 document structure:

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Page Title</title>
</head>
<body>
  <h1>Welcome to Web Development</h1>
</body>
</html>

2. Core Elements Cheat Sheet

<h1> to <h6>

Headings, ranging from highest structural priority (<h1>) to lowest (<h6>).

<p>

Standard paragraph block for body text copy.

<a href="...">

Anchor links to target external URLs or internal IDs.

<img src="..." alt="...">

Embeds images with mandatory alternative text for accessibility.

3. Semantic HTML Structure

Avoid using generic <div> tags for everything. Use semantic layout tags to ensure proper accessibility and SEO indexing:

  • <header>: Top navigation bars or article introductions.
  • <nav>: Main navigation menu links.
  • <main>: Primary unique content area of the document.
  • <section> & <article>: Grouping related components or standalone content stories.
  • <aside>: Sidebars or auxiliary content blocks.
  • <footer>: Bottom copyright, privacy links, and contact information.
